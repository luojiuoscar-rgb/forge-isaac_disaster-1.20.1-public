# 无头宝（Headless Baby）

沿用波比弟弟的身体、手臂和尖尾，移除头部及全部动画。保留同系列的轮廓、干净手臂和侧背面像素明暗，改为参考图的灰粉肤色，顶部绘制深红颈部断口，正面红色痕迹向下收窄。

- `headless_baby.bbmodel`：可编辑源模型，内嵌 64×64 贴图与独立图层。
- `headless_baby.png`：正式贴图，逻辑 UV 64×64。
- `HeadlessBabyModel.java`：Forge 1.20.1 / Mojang mappings 模型导出参考，尚未接入游戏实体。

8 个方块，6 个分组，96 个三角面。无 idle、无攻击动画。保留的身体几何、枢轴和 UV 与波比弟弟一致。
