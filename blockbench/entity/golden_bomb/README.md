# 金炸弹（Golden Bomb）

与相邻普通炸弹使用相同的 9 方块几何及 UV：顶部中央有两段短小、向一侧折弯的立体引线，下段旋转 30°、上段旋转 75°，根部嵌入弹壳。删除原有平面绳线，保留中央小孔口。引线沿用普通炸弹的棕色编织贴图。

金色弹壳与白色骷髅沿用已确认的弱方向性材质；四周基础亮度均衡。

- `golden_bomb.bbmodel`：可编辑源，内嵌 128×64 贴图与 5 个图层。
- `golden_bomb.png`：正式 PNG，逻辑 UV 128×64，1 像素/模型单位。

复用 `../isaac_bomb/IsaacBombModel.java`，不另存重复几何导出。9 个方块、108 个三角面，无点燃或待机动画。本次为模型源文件更新，尚未接入游戏渲染器。
