# 波比炸弹（Bobby Bomb）动画预览

沿用普通炸弹已确认的主体、平铺材质、骷髅和短弯折引线。按照参考图在背面（+Z）增加发条钥匙式旋转把手：短连接轴、双叶金属框与两个真实镂空窗。机械件使用低对比铁灰贴图。

- `bobby_bomb.bbmodel`：可编辑源，内嵌贴图。
- `bobby_bomb.png`：128×64 正式 PNG，1 像素/模型单位。
- `BobbyBombModel.java`：Forge 1.20.1 / Mojang mappings 模型导出参考。

19 个方块、2 个分组、228 个三角面，新增机械件为 10 方块。双叶外轮廓在中间收腰，避免呈现矩形拉手外观。`winding_key` 轴心在 [0,8,10.5]，`fuse` 动画使它绕 Z 轴匀速旋转，每秒一圈并循环。当前仅供外观审查，尚未接入游戏渲染器。

- `BobbyBombAnimations.java`：通过 Blockbench 原生导出的 Forge 1.20.1 动画参考，包含 `FUSE`。

`fuse` 长度 1 秒，0/90/180/270/360 度五个线性关键帧。仅 `winding_key` 分组转动，炸弹主体与引线保持静止。循环衔接保持同一转速；动画已保存到 `.bbmodel`，尚未接入游戏。
