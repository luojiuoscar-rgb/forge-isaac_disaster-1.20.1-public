# 普通炸弹（Isaac Bomb）

保留已确认的方块主体、阶梯收边、弱方向性灰黑材质和正面骷髅。顶部中央新增两段短立体引线：下段倾斜 30°、上段倾斜 75°，形成朝一侧折弯的低矮轮廓。引线根部嵌入弹壳，贴图只保留 2×2 中央暗色孔口，移除原有平面绳线。引线使用克制的棕色编织像素，末端略暗。

- `isaac_bomb.bbmodel`：可编辑源，内嵌完整贴图与 5 个图层。
- `isaac_bomb.png`：128×64 PNG，逻辑 UV 128×64，1 像素/模型单位。
- `IsaacBombModel.java`：Forge 1.20.1 / Mojang mappings 几何导出参考，保留旋转引线。

9 个方块，108 个三角面；较原版只增加 2 个方块、24 个三角面。主体 16×16×16 模型单位，立体引线最高约高出顶面 2.1 单位。无点燃或待机动画，未接入游戏渲染器；当前游戏 TNT 渲染保持原状。金炸弹已同步相同的立体引线，见 `../golden_bomb/`，两者共用本目录的 Java 模型导出。
