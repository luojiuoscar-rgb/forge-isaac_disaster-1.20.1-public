# 粘性炸弹（Sticky Bomb）

沿用普通炸弹主体与两段短弯引线。中性冷灰底层上交错缠绕白色、浅灰蛛丝，各面保持相近材质明度，以窄线、丝束边缘和局部缝隙体现包裹感。以用户在四个侧面手绘的分叉裂口为基础，保留轮廓和位置，将纯黑调整为冷灰深浅变化、灰色收尖及窄接触阴影，并在少数交叉处补上浅灰蛛丝；已移除原先看似五官的三个黑点。没有底部拖出的蛛网，也没有额外蛛丝几何。

- `sticky_bomb.bbmodel`：可编辑分层源文件。
- `sticky_bomb.png`：128×64 不透明像素贴图，1 像素/模型单位。
- `StickyBombModel.java`：Forge 1.20.1 / Mojang mappings 模型导出参考。

9 个方块、108 个三角面，无动画。弹体尺寸、UV 与普通炸弹一致；原短引线像素保留。本次为 Blockbench 外观预览，未修改游戏运行时代码。

蛛丝主色取自本地 Minecraft 1.20.1 原版 `assets/minecraft/textures/block/cobweb.png`：RGB (255,255,255)、(228,233,233)、(196,206,210)。灰色底层和裂痕保持低饱和度，去除之前的紫色色偏。

本次精修保留用户原始绘画图层，在独立顶层细化 77 个纯黑裂口像素及相邻边缘。引线部分包含用户修改的亮色端头，精修时按当前用户版本原样保留。
