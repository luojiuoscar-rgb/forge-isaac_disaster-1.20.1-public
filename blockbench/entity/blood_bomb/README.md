# 鲜血炸弹（Blood Bomb）

保留普通炸弹原有方形主体的血袋材质，外壳采用真实 RGBA 半透明塑料膜、浅灰封边和少量白色反光。袋内用两个独立方块表现深红血液，液面位于 y=10.5，上半部保留透明空腔。袋顶保留短弯折结构并涂成深灰管状材质。没有骷髅或五官，无动画。

- `blood_bomb.bbmodel`：可编辑分层源文件。
- `blood_bomb.png`：128×128 单张 RGBA 图集，1 像素/模型单位。
- `BloodBombModel.java`：Forge 1.20.1 / Mojang mappings 导出参考。

11 个方块、132 个三角面。袋体宽16、高16、厚16模型单位，顶部短管除外。7 个袋壳方块的内部接合面纹理均全透明，避免隐藏表面重复叠加。血液先于袋壳绘制，Blockbench 内部填充方块使用 `render_order: behind`。

本次为 Blockbench 外观预览，未接入游戏。未来渲染器应先画不透明血液和短管，再画半透明袋壳；Java 几何导出不包含此绘制次序或材质绑定。

已按用户反馈恢复普通炸弹的原始 16×16×16 方形外壳：7 个袋壳方块及短引线的几何、原始 UV 偏移均与 `isaac_bomb.bbmodel` 一致。内部血液同步扩大以适配原体积，液面高度仍为 y=10.5。扩展图集下半区容纳血液 UV，所有面保持 1 像素/模型单位，透明膜、袋边和液面材质继续保留。
