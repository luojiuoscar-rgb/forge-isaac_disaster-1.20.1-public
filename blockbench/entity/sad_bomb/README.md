# 悲伤炸弹（Sad Bomb）

沿用普通炸弹的九方块主体、短弯折立体引线和 UV；外壳略调亮，保持弱方向性、低对比像素材质。将骷髅替换为哭泣表情，双眼保持水平，白色高光一致，嘴巴居中下弯；浅蓝泪滴仅保留一像素的高低差。眼泪直接画在正面贴图，不新增透明面或几何。

- `sad_bomb.bbmodel`：可编辑源，内嵌 128×64 贴图和 5 个图层。
- `sad_bomb.png`：正式 PNG，逻辑 UV 128×64，1 像素/模型单位。
- `SadBombModel.java`：Forge 1.20.1 / Mojang mappings 模型导出参考。

9 个方块、108 个三角面，无动画。当前为独立外观预览，尚未接入游戏。
