# 鲍勃炸弹（Bob's Bomb）

普通炸弹的腐烂绿色材质变体，保留主体、阶梯收边、短弯折立体引线及 UV。外壳采用参考图的灰绿配色，正面绘制大张口、上沿两颗浅绿小牙、一只空洞眼与一只 X 眼；侧面、背面和顶部补充较小斑纹。主体基础明暗继续保持弱方向性。

- `bobs_bomb.bbmodel`：可编辑源，内嵌 128×64 贴图和 6 个图层。
- `bobs_bomb.png`：正式 PNG，逻辑 UV 128×64。
- `BobsBombModel.java`：Forge 1.20.1 / Mojang mappings 模型导出参考。

9 个方块，108 个三角面，无动画；引线和模型几何均与普通炸弹一致。本次仅制作外观预览，尚未接入游戏渲染。

正面凹陷采用不规则轮廓，空洞眼与口腔内部保留黑色及深灰绿层次；两颗小牙均连接上唇，取参考图的灰绿色。
