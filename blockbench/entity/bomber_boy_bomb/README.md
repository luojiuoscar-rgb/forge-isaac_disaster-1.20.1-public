# 炸弹人炸弹（Bomber Boy）

沿用普通炸弹主体与短弯引线。参考用户提供的 Bomber Boy 炸弹图，绘制灰白头盔、深色矩形框及从上沿垂下的两道长眼睛，面罩内部保留灰色。头盔的浅色边缘延续到两侧和背面，材质没有固定单侧高光渐变。

- `bomber_boy_bomb.bbmodel`：可编辑分层源文件。
- `bomber_boy_bomb.png`：128×64 不透明贴图，1 像素/模型单位。
- `BomberBoyBombModel.java`：Forge 1.20.1 / Mojang mappings 导出参考。

9 个方块、108 个三角面、无动画。几何、UV 和引线材质与原普通炸弹一致。当前为 Blockbench 外观草稿，未接入游戏运行时。
