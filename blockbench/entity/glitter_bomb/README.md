# 闪光炸弹（Glitter Bomb）粉色材质

根据用户参考图制作简洁粉色弹壳。使用五个接近的粉色阶，只在底缘和结构接缝处略微加深，各面没有固定单侧高光。弹壳不绘制骷髅或五官。沿用普通炸弹九方块主体、UV 与短弯引线，引线像素原样保留。

- `glitter_bomb.bbmodel`：独立可编辑源，内嵌 128×64 贴图和图层。
- `glitter_bomb.png`：不透明粉色贴图，1 像素/模型单位。

9 个方块、108 个三角面，无动画。运行时可复用 `isaac_bomb/IsaacBombModel.java` 的几何并切换贴图。本次为 Blockbench 材质预览，未修改游戏代码。
