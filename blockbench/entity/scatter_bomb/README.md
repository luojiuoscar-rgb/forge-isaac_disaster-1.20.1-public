# 分裂炸弹（Scatter Bomb）玻璃材质预览

沿用普通炸弹九方块主体与短弯折引线。每个外表面采用低透明度烟灰玻璃底色、较深像素边框及少量浅色反光。引线保持不透明。内部接合区域用全透明像素隐藏，避免多层内部方块表面堆叠。纹理 RGB 无固定单侧高光渐变。

- `scatter_bomb.bbmodel`：可编辑源，128×64 贴图及分层；双面玻璃预览。
- `scatter_bomb.png`：带真实 RGBA 半透明度的正式 PNG，逻辑 UV 128×64。
- `ScatterBombModel.java`：Forge 1.20.1 / Mojang mappings 模型导出参考。

12 个方块，无动画。其中 9 个为原炸弹，新增苍蝇身体与双翼共 3 个方块。双翼固定上抬 30 度，内部苍蝇保持静态。弹壳尺寸、UV 与玻璃像素均未改变；苍蝇图案占用原 128×64 图集的空闲区。半透明与镂空使用同一张图；未来接入游戏应使用支持半透明混合的实体 RenderType，单纯换 PNG 或 cutout 无法保证该效果。本次未修改游戏渲染器。

内部苍蝇的形状参考 `blockbench/creature/blue_fly/blue_fly.bbmodel`，按炸弹参考图改为近黑色方块身体与灰色镂空双翼。身体边长 3 模型单位，展开双翼宽约 9.48，高约 4.69，悬在弹壳中央，与玻璃内壁留有间隔。未修改独立蓝苍蝇源文件，也未导入其动画。

Blockbench 将三个内部苍蝇方块设为 `render_order: behind`，先画内部再画玻璃以保证预览可见。此项不是 Java 导出中的引擎材质配置：未来游戏集成应先绘制不透明苍蝇，再绘制半透明玻璃，不能用整只模型的单一 cutout 绘制替代。
