# 硫磺火炸弹（Brimstone Bomb）

保留普通炸弹原有 16×16×16 方形主体与短弯引线。加大的两角各用三段方块形成外弯再向内收的轮廓，左右镜像。正面绘制红色填充充分、带窄黑色眉线的凶狠斜眼、低矮的暗色嘴部、两颗从上唇向下露出的小灰白上牙，以及红色硫磺火标记（双横线与底部双环）。

- `brimstone_bomb.bbmodel`：独立可编辑源，内嵌分层贴图。
- `brimstone_bomb.png`：256×128 不透明 PNG，逻辑 UV 128×64，2 像素/模型单位。
- `BrimstoneBombModel.java`：Forge 1.20.1 / Mojang mappings 几何导出参考。

15 个方块、180 个三角面，无动画。细节集中在正面和角的轮廓，侧面和背面使用相同明度分布的灰色材质。此为已确认并保存在 master 的外观资源，尚未接入游戏渲染器。
