# Fast Bombs 闪电标识材质

沿用普通炸弹九方块主体、短弯引线与逻辑 UV。深灰弹壳的四周使用相同亮度分布，不绘制固定单侧高光；正面以 6×10 像素范围的黄色折线闪电替代骷髅图案。闪电的上下端接近同一中轴，保留清楚的单道折角，整体竖直居中；高度按用户反馈从 8 像素增至 10 像素；侧面与背面保留简洁深灰材质。

- `fast_bomb.bbmodel`：独立可编辑源，内嵌 128×64 贴图和图层。
- `fast_bomb.png`：正式 PNG，1 像素/模型单位，不透明材质。

9 个方块、108 个三角面，无动画。运行时可复用 `isaac_bomb/IsaacBombModel.java` 的几何并切换贴图。本次仅制作 Blockbench 外观预览，未修改游戏运行时代码。
